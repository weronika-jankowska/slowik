# Uruchomienie aplikacji

Po skopiowaniu repozytorium do lokalnego folderu należy otworzyć folder w Visual Studio Code, a następnie uruchomić terminal (w VS Code).
Następnie konieczne są instalacje bibliotek:

npm install pitchy lucide-react
npm install -D tailwindcss postcss autoprefixer
npm install @tailwindcss/vite tailwindcss

Po wykonaniu tych kroków aplikację można uruchomić, wpisując w terminalu:
npm run dev

W terminalu pojawi się link, który należy uruchomić w dowolnej przeglądarce.
