# Uruchomienie aplikacji

Po skopiowaniu repozytorium do lokalnego folderu można otworzyć folder w Visual Studio Code, a następnie uruchomić terminal (w VS Code).
Następnie należy uruchomić polecenia:

npm install

npm run dev


W terminalu pojawi się link, który należy uruchomić w dowolnej przeglądarce.
